# SuperAdmin Portal

SuperAdmin functionality for application management.

## Features
- Application Management
- LLMOps Management (providers, routing, quotas, costs)
- MLOps Management (models, experiments, deployments, monitoring)
- Marketing Plan Interface (combo packs, offerings)
- Tenant Management
- System Configuration
- Audit Logs

Implemented in apps/api/routers/admin.py and core/models/admin.py
